\section{Context edits and post-training consistency}
\label{sec:C08:consistency}
MemoryWalker identifies two distinct errors when training on edited rollouts: conditioning earlier actions on later compressed information, and reconstructing a full context different from the live context the agent actually saw. Its exact tree-consistent methods and approximate distillation route address different implementation regimes~\cite{j2026memorywalker}. The general lesson is a conditioning invariant. For every supervised or policy-gradient action, the training distribution must represent the information and visibility under which that action was generated, unless the method explicitly defines a counterfactual objective and corrects for the difference.

Consider an agent that queries a tool, observes a fact, and later writes a summary. Training its earlier query on the final summary leaks the tool result backward in time. Training a later answer on a reconstructed full history can instead expose information the live agent had already evicted. These errors have opposite structures but share the same root: a linear stored transcript is not always the computational history of an editing agent. Branch identity, masks, summaries, and action-time context versions are necessary to reconstruct the actual conditional distribution.

An implementation can materialize separate branches or use an attention mask that expresses their visibility. The latter is not merely a convenient packed sequence; its mask must reproduce the branch computation exactly. Specialized masks can conflict with optimized attention kernels, so correctness and performance must be measured together. An approximate consistency loss can be valuable when exact materialization is expensive, but residual divergence should be reported rather than described as equivalence. A lower training loss under a leaked context is not evidence that the deployable policy learned a better decision rule.

The corresponding audit is concrete. For a fixed checkpoint and retained rollout, recompute action logits under the captured live contexts. Compare them with the training pipeline's logits before any parameter update. Disagreement can reveal serialization, masking, position, or context-reconstruction errors independently of learning. Then repeat after enabling compaction and branch packing. This zero-update consistency check is particularly useful because it can falsify the data pipeline without requiring a large and noisy downstream training experiment.
