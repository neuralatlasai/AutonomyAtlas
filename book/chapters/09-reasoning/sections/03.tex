\section{Self-consistency and answer aggregation}
\label{sec:C09:voting}
Self-consistency samples reasoning paths and aggregates their final answers, rather than trusting one path~\cite{wang2022selfconsistency}. It approximates the answer mass induced by the model and decoding procedure. The modal answer can still be wrong. Under independent binary correctness with $p>1/2$, a majority vote has an error probability bounded by $\exp[-2k(p-1/2)^2]$ through Hoeffding's inequality, with tie handling specified separately. If the model's dominant misconception makes $p<1/2$, increasing the sample count can make the wrong majority more stable. The bound's premises are stronger than merely using different random seeds.

Answer equivalence is itself a component. Exact string voting can split mathematically equivalent expressions or merge ambiguous natural-language answers incorrectly. A canonicalizer may simplify arithmetic expressions, normalize units, or compare structured actions. That canonicalizer needs a correctness contract. For tool use, two actions that have the same apparent intent can differ in permissions, resource identity, or irreversible side effects. Voting on a prose description before argument validation can select an action family whose actual executable instances are all invalid. Aggregation should operate on a representation appropriate to the task's semantics.

Diversity interventions include changing prompts, sampling parameters, decompositions, tools, or model checkpoints. Each can reduce shared errors while introducing new confounds and costs. A heterogeneous team is not automatically independent, particularly when all members read the same flawed summary. A useful study measures error overlap and the selector's performance rather than relying on role names as evidence of diversity. When candidates have access to different evidence, retain that provenance so that disagreement can motivate another observation rather than being settled by a numerical majority alone.

In stateful tasks, candidates also need isolation. If the first attempt modifies a repository, the second is not a repeated trial from the same initial state unless the environment is restored. Shared persistent memory can make later attempts better informed, but the resulting process is adaptation rather than independent sampling. Both are legitimate experimental objects. They should be reported separately because their reliability, resource use, and deployment assumptions differ. A best-of-five outcome with accumulated memory does not estimate the same quantity as five fresh attempts.
