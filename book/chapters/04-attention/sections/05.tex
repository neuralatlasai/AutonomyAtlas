\section{Bandwidth limits and latency distributions}
\label{sec:C04:bandwidth}
A simple lower-bound model distinguishes arithmetic and movement. If an operation requires $F$ floating-point operations and transfers $D$ bytes through a bottleneck interface with usable rates $P$ and $W$, then its duration is at least $\max(F/P,D/W)$ under ideal overlap. This is a lower bound, not a performance prediction. Kernel launches, synchronization, indexing, cache misses, and queueing add costs. The relevant bandwidth is the measured rate for the actual access pattern, not an advertised peak. Small batches and scattered page accesses may fail to approach that peak.

For long-context decode, repeatedly reading keys and values can dominate the attention component. Grouping more sequences can improve weight reuse and hardware utilization, but also increases active KV traffic and waiting time. An agent service should report time to first token, inter-token latency, complete action latency, and end-to-end task latency. A tool call that takes seconds can hide a model optimization in the mean while the optimization still matters for the tail of interactive steps. Conversely, aggressive batching can increase the time before a safety-critical confirmation reaches the execution boundary.

Queueing creates another source of misleading comparisons. At low offered load, both implementations may have small queues. Near capacity, a modest service-rate difference can produce a large latency difference because requests accumulate. A benchmark that measures only completed-request throughput can conceal dropped or timed-out work. Report offered load, admitted load, completed load, error rate, and latency percentiles together. Open-loop arrivals are useful for exposing overload because the load generator does not automatically slow down when responses become late. Closed-loop tests answer a different question about a fixed client population.

Cache offload shifts the bottleneck. A host-memory cache can permit more paused sessions while introducing transfers on resumption. If $D_{\mathrm{resume}}$ bytes must cross a link with sustained bandwidth $W_{\mathrm{link}}$, transfer time alone is at least $D_{\mathrm{resume}}/W_{\mathrm{link}}$ before overlap and scheduling effects. Compression may reduce transferred bytes while adding quantization or decompression work. A system that advertises more simultaneous sessions should disclose whether those sessions are immediately executable, offloaded, or represented only by a durable log requiring prefill. These states have different practical meanings for interactive agents.
