\section{The agent is the unit of analysis}\label{sec:C01:01}
An agentic system is a coupled decision process whose behavior depends on a predictive model and on the machinery that determines what the model observes, which actions can execute, what persists, and how success is established. Treating the model endpoint as the whole system hides variables that can dominate an experiment. A model that proposes a valid shell command has not thereby completed a repository repair. The command must execute in the intended checkout, its effects must survive interruption, the resulting program must satisfy the specification, and the evidence must reach a decision maker. Each transition introduces an independently testable mechanism.

Let the operational configuration be
\begin{equation}
 \Xi=(f_\theta,q,\delta,g_\eta,U,\mathcal T,\mathcal R,V,A),
 \label{eq:c01:configuration}
\end{equation}
where $f_\theta$ is the model, $q$ the tokenizer and serialization interface, $\delta$ the decoding configuration, $g_\eta$ the context constructor, $U$ the persistent-state update rule, $\mathcal T$ the tool interface, $\mathcal R$ the execution runtime, $V$ a collection of validators, and $A$ the authorization mechanism. None of these components is assumed correct. The environment supplies observations and receives effects. A complete trajectory includes attempted actions, rejected actions, tool errors, state mutations, validator outputs, and termination, rather than only model messages. This boundary permits scientific attribution: changing a model and changing a harness are different interventions even if both increase a benchmark score.

The term \emph{agentic} identifies controlled interaction, not a particular software package or level of intelligence. A fixed workflow can invoke a powerful model without delegating its control flow. Conversely, a modest model can choose among tools and adapt a plan, while remaining severely limited in competence. Useful architectural descriptions therefore state which decisions are model-controlled, which are deterministic, and which require external authority. The ReAct formulation connects reasoning and environment actions, while SWE-agent demonstrates that the interaction interface around a model is itself an important engineering object. Neither establishes that every autonomous loop has useful generality~\cite{yao2022react,yang2024sweagent}.

Three boundaries are especially consequential. The \emph{epistemic boundary} separates available observations from latent environment state. The \emph{authority boundary} separates a plausible model proposal from an executable permission. The \emph{commit boundary} separates an attempted operation from an effect that has become durable or externally visible. A retrieved document may cross the epistemic boundary without crossing the authority boundary: observing an instruction does not grant permission to obey it. A tool response may report success without crossing a verified commit boundary: the operation may have been accepted asynchronously and later failed. Reliable autonomy requires all three boundaries to be represented explicitly.

This perspective explains why the ecosystem cannot be reduced to a list of models or SDK names. Tokenizers determine representational interfaces; context managers select current evidence; sessions preserve continuity; memory services retain and reinterpret information; skills package procedures; protocols transport capabilities and results; runtimes mediate side effects; evaluators define what is counted as success. Their interactions, rather than their isolated presence, are the main technical subject of this book.

October 2026 evidence makes this boundary experimentally consequential. TraceTrial-Bench separates task outcomes from harness-criterion satisfaction, using native traces and environment evidence rather than treating a successful deliverable as proof that every runtime obligation held~\cite{ch01_tracetrial2026}. ASAP evaluates frozen pretrained models through completion-based trajectory continuation, with reference prefixes and bounded recovery interventions~\cite{ch01_asap2026}. Its observed competence therefore belongs to that elicitation protocol, not to an unaided model in an unspecified interface. These studies motivate recording both the system under test and the apparatus that measures it; neither a benchmark name nor a model name uniquely identifies the experiment.
