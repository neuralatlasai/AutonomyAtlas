- License: MIT; the complete original notice is tracked in [`et-book-LICENSE.txt`](et-book-LICENSE.txt) and served as [`public/licenses/et-book.txt`](../public/licenses/et-book.txt).
- Typeface design: Dmitry Krasny, Bonnie Scranton, and Edward Tufte. The upstream README credits Adam Schwartz with conversion from the original font files.
- Font binaries are unmodified. The italic file is renamed locally; its source face is display italic with old-style figures. No binary conversion or subsetting was performed.
